⚡ API Setup & Integration Guide

আপনার ওয়েবসাইটে বা অ্যাপ্লিকেশনে আমাদের IELTS লাইব্রেরি যুক্ত করার সম্পূর্ণ গাইড। API Key ছাড়া অথবা API Key সহ — যেকোনো পদ্ধতিতে সহজেই ইন্টিগ্রেট করুন।

🔒

নিরাপত্তা ও প্রাইভেসি প্রটেকশন: মূল সিক্রেট API Key পাবলিক গাইডে কখনোই প্রকাশ করা হয় না। এখানে YOUR_API_KEY প্লেসহোল্ডার হিসেবে ব্যবহৃত হয়েছে। নিজস্ব ডোমেইনে রিডার হোস্ট করার জন্য অনুমোদিত কী পেতে অ্যাডমিন প্যানেল থেকে যোগাযোগ করুন।

🚀 ১. API Key ছাড়া ইন্টিগ্রেশন (Direct Embed)

এটি সবচেয়ে সহজ ও ঝামেলামুক্ত পদ্ধতি। আপনার ওয়েবসাইটে কোনো API Key বা জটিল কনফিগারেশন ছাড়াই বইয়ের লিঙ্ক বা বাটন বসাতে পারেন। লিঙ্কে ক্লিক করলেই সুরক্ষিত ডায়নামিক ১.৫ সেকেন্ডের টোকেন তৈরি হয়ে সরাসরি লাইব্রেরিতে বই ওপেন হবে।

✨ সুবিশাল সুবিধা:

  • ✓ কোনো API Key কনফিগার করার প্রয়োজন নেই।
  • ✓ আপনার সাইটে আলাদা রিডার পেজ তৈরি করতে হবে না।
  • ✓ স্বয়ংক্রিয়ভাবে এক্সপায়ার-প্রুফ 0ms সিকিউর টোকেন জেনারেট হয়।
  • ✓ সব ডিভাইসে শতভাগ ফাস্ট ও রেসপন্সিভ।

🛡️ ২. API Key সহ ইন্টিগ্রেশন (Custom Domain Reader)

আপনি যদি চান বই পড়ার রিডারটি আমাদের ডোমেইনের পরিবর্তে আপনার নিজস্ব ডোমেইনে (yourwebsite.com/book/) চালু থাকবে, তবে অনুমোদিত API Key ব্যবহার করে এই মোডটি সক্রিয় করুন।

🔑

কী প্লেসহোল্ডার সতর্কতা: নিচে কোডে থাকা YOUR_API_KEY এর জায়গায় আপনার অ্যাডমিন থেকে প্রাপ্ত সিক্রেট কী বসান। পাবলিক পেজে কখনোই আপনার গোপন কী প্রদর্শন করবেন না।

ধাপ ১: আপনার সাইটের পেজে বাটন ও স্ক্রিপ্ট (API Key সহ)

Step 1: Partner Page Button 
<!-- বাটন বা লিংক -->
<a href="#" class="btn btn-primary" data-book="cambridge-ielts-19">
  📖 Read Cambridge IELTS 19

<!-- Embed Script (API Key সহ) -->
<script 
  src="https://free.ieltsbooks.workers.dev/api/embed.js"

📡 সার্ভার API এন্ডপয়েন্টস রেফারেন্স (Backend / REST API)

আপনার কাস্টম সার্ভার, মোবাইল অ্যাপ বা অটোমেশনের জন্য নিচের এন্ডপয়েন্টগুলো ব্যবহার করতে পারেন:

Method Endpoint Description Auth Requirement
GET /api/embed.js ক্লিকের সাথে সাথে 0ms ডাইনামিক টোকেন জেনারেটর স্ক্রিপ্ট পাবলিক (Key সহ বা ছাড়া)
GET /api/data-books সব বইয়ের আইডি ও স্লাগ লিস্ট Header: x-api-key: YOUR_API_KEY
GET /api/books/resolve বইয়ের আইডি থেকে সুরক্ষিত ডাইনামিক লিঙ্ক রেজল্যুশন Query: ?key=YOUR_API_KEY
GET /api/book-info একক বইয়ের বিস্তারিত তথ্য ও ডাউনলোড লিঙ্ক Header: x-api-key: YOUR_API_KEY
cURL API Request Example 
curl -X GET "https://free.ieltsbooks.workers.dev/api/data-books" \
  -H "x-api-key: YOUR_API_KEY"

⏱️ টোকেন নিরাপত্তা ও এক্সপায়ারি পলিসি

  • ১. ১.৫ সেকেন্ডের কঠোর মেয়াদ (Strict 1.5s Expiry): প্রতিটি টোকেন জেনারেট হওয়ার ১.৫ সেকেন্ডের মধ্যে ব্রাউজারে ভ্যালিডেশন হতে হবে। পুরনো বা কপি করা লিঙ্ক সরাসরি 404 লিঙ্কে রিডাইরেক্ট হবে।
  • ২. অ্যান্টি-স্ক্র্যাপার প্রটেকশন: সার্ভারে সরাসরি বট বা স্ক্র্যাপার রিকোয়েস্ট ঠেকানোর জন্য ডায়নামিক সাইনিং ব্যবহৃত হয়।
  • ৩. ব্রাউজার নো-ক্যাশ পলিসি: সংবেদনশীল লিঙ্ক ব্রাউজার হিস্ট্রি বা ক্যাশে সেভ হওয়া থেকে আটকাতে no-store, no-cache হেডার সংযুক্ত থাকে।
